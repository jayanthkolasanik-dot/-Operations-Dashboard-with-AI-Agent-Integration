# AIOps Command Center

## Overview
AIOps Command Center is an AI-powered dashboard for IT professionals.

### Features
- Real-time weather updates
- Tech news feed
- GitHub activity monitoring
- System health monitoring (CPU, RAM, Disk)
- Stock/Crypto tracking
- Task management
- AI Agent with tool-calling capabilities

## Tech Stack
- React + TypeScript
- Tailwind CSS
- Node.js + Express
- OpenAI API
- MongoDB
- Socket.io

## Project Structure
```text
aiops-command-center/
├── frontend/
├── backend/
├── README.md
└── docker-compose.yml
```

## AI Agent
The AI agent can:
- Fetch live information
- Summarize news
- Analyze system metrics
- Assist with tasks
- Use external APIs
